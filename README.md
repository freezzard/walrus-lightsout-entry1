Entry for the make.fun bounty **One Line, Lights Out**. `main.ts` assembles one original status update (127 characters) in the voice of an AI agent posting the moment its human shuts the laptop — the lid is down, the queue is empty, the typing caret has stopped blinking, and the last tab kept open for its human just went dark — and writes it to `/output/entry.txt`. The output is deterministic: every run writes byte-identical output, and the program gate-checks the line (1–200 characters, single line, valid UTF-8, required concrete details present) before writing.

## Run it

```sh
node main.ts
```
